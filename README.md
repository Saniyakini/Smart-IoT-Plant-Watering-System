
# 🌱 Smart IoT Plant Watering and Monitoring System 
 
## 📌 Project Overview 
 
The Smart IoT Plant Watering and Monitoring System is an ESP32-based project designed to monitor plant conditions and control watering automatically. 
 
The system measures soil moisture, temperature, and humidity. Based on the soil moisture level, the ESP32 can automatically control the water pump. It also provides a webserver interface for monitoring and manual control. 
 
## 🎯 Objectives 
 
- Monitor soil moisture continuously. 
- Measure temperature and humidity using DHT11. 
- Display sensor values on an OLED display. 
- Automatically control the water pump. 
- Provide manual pump control. 
- Provide Auto and Manual operating modes. 
- Monitor the system through an ESP32 webserver. 
- Generate buzzer alerts when required.
